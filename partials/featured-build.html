AssetCare: a production-deployed Java, Angular and Kubernetes application.

AssetCare

assetcare.janaka.me · asset and maintenance management, reference application

Live

Idea to public URL by one engineer: Java 25 and Spring Boot 4.1 behind an Angular 22 front end, Keycloak identity, PostgreSQL 18 with Liquibase, S3-compatible storage, all running on Kubernetes (K3s) with Helm, Traefik and a Let's Encrypt certificate on a Hetzner Cloud server created from Terraform. Tested at every level, scanned, signed and released through GitHub Actions. AI-assisted engineering accelerated the implementation, the investigation and the documentation; the architecture, security, validation and production decisions stayed engineering-led.
