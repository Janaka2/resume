# Janaka AI Research Tracker

A lightweight repo to track **latest AI research and development activity** in a way that is easy to maintain week by week.

## What this repo now helps you do

- Track major AI trend areas (agents, multimodal, evals, safety, infra, open-source models).
- Capture paper/product updates in a consistent format.
- Build a gradual weekly learning and implementation rhythm.
- Turn research notes into practical experiments.

## Suggested repo workflow (step by step)

1. **Weekly scan (30-60 min)**
   - Review top new papers, model releases, and tooling updates.
   - Add 3-5 items using the research entry template.
2. **Signal scoring (15 min)**
   - Score each item by impact, maturity, and relevance to your goals.
3. **Monthly deep dive (2-4 hours)**
   - Pick 1 trend area and summarize key movement.
   - Implement one mini prototype in your lab/project.
4. **Quarterly refresh (1-2 hours)**
   - Update the trend map priorities.
   - Archive stale areas and add emerging ones.

## Repository structure

- `index.html` – public landing page for AI/Agents.
- `research/README.md` – operating guide for research tracking.
- `research/trend-map-2026.md` – living map of priority trend areas.
- `.github/ISSUE_TEMPLATE/research-entry.md` – reusable entry template for new updates.

## Fast start

- Read `research/README.md`.
- Open `research/trend-map-2026.md` and pick one area as your **focus this month**.
- Create your first entry using the issue template.
