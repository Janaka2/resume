Blueprint

An MCP-enabled agent skeleton.

A starter pattern for robust orchestration over the Model Context Protocol (MCP): explicit tool capabilities discovered from MCP servers, strict I/O contracts and policy-aware handlers. It grew out of the Job-Research Agent in the Lab. The runnable version is the MCP agent skeleton, a small Python stdio client with a tool router and an agent loop; the background is in MCP for agent integrations.

const capabilities = [
  {
    name: 'searchDocs',
    description: 'Search company knowledge base',
    parameters: { query: 'string' }
  },
  {
    name: 'createTicket',
    description: 'Create support ticket',
    parameters: { title: 'string', body: 'string' }
  }
];

const agentPrompt = `
You can call: searchDocs, createTicket.
Prefer searchDocs for evidence, createTicket on explicit request.
Return strict JSON payload for selected capability.
`;

1 · Capability list

Each operation is an MCP tool: explicit, typed and discoverable through the server's tools/list, so both the developer and the model know what a valid action looks like.

2 · Prompt policy

The prompt sets selection rules and output structure, which is what removes the ambiguity that unsafe behaviour hides in.

3 · Strict output

A strict JSON payload makes downstream execution predictable and cheap to validate.

Production patterns

  • RAG + verification — ground every answer in trusted internal context, and verify the assumption before acting on it. Worked example: the FAISS chatbot in the Lab.
  • DLQ + guardrails — route malformed output to a dead-letter queue with triage and alerting.
  • Streaming UX — show partial responses and phase-level progress on anything long-running.
  • Observability — traces, metrics, prompt versions and a feedback loop, or quality gaps stay invisible.

Research tracker

  • Weekly signal scan — collect three to five updates that actually matter.
  • Score by impact — rank on relevance, maturity and return.
  • Monthly synthesis — turn the reading into one focused implementation.
  • Quarterly reset — drop the noise and sharpen the roadmap themes.
