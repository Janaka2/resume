Blueprint

An MCP-enabled agent skeleton.

A starter pattern for robust orchestration: explicit capabilities, strict I/O contracts and policy-aware handlers.

const capabilities = [
  {
    name: 'searchDocs',
    description: 'Search company knowledge base',
    parameters: { query: 'string' }
  },
  {
    name: 'createTicket',
    description: 'Create support ticket',
    parameters: { title: 'string', body: 'string' }
  }
];

const mcpPrompt = `
You can call: searchDocs, createTicket.
Prefer searchDocs for evidence, createTicket on explicit request.
Return strict JSON payload for selected capability.
`;

1 · Capability list

Each operation is explicit, typed and discoverable, so both the developer and the model know what a valid action looks like.

2 · Prompt policy

The prompt sets selection rules and output structure, which is what removes the ambiguity that unsafe behaviour hides in.

3 · Strict output

A strict JSON payload makes downstream execution predictable and cheap to validate.

Production patterns

  • RAG + verification — ground every answer in trusted internal context, and verify the assumption before acting on it.
  • DLQ + guardrails — route malformed output to a dead-letter queue with triage and alerting.
  • Streaming UX — show partial responses and phase-level progress on anything long-running.
  • Observability — traces, metrics, prompt versions and a feedback loop, or quality gaps stay invisible.
