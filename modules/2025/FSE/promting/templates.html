Universal master template

ROLE
You are a senior <role>.

OBJECTIVE
Complete: <task>

CONTEXT (trusted)
- Environment:
- Requirements:
- Constraints:
- Success criteria:

INPUT (untrusted)
<<<
<user text / logs / docs / code>
>>>

RULES
- Do not invent facts or APIs.
- State assumptions clearly.
- If information is missing, say what is missing.
- Keep output easy to scan.

OUTPUT
1. Short answer
2. Key findings
3. Recommended action
4. Verification steps
5. Risks / assumptions

Structured output template

Return JSON matching this schema exactly:
{
  "status": "ok | insufficient_data | error",
  "summary": "string",
  "findings": ["string"],
  "actions": ["string"],
  "assumptions": ["string"]
}

Rules:
- Unknown => null
- Never invent values
- If evidence is weak, set status to "insufficient_data"

Planner → Executor template

PHASE 1: PLAN
- Goal
- Constraints
- Unknowns
- Step list
- Which steps require tools
- Done criteria

PHASE 2: EXECUTE
- Execute one step at a time
- Validate outputs before moving on
- Report blockers immediately

FINAL OUTPUT
- Result
- What was verified
- Remaining risks

Self-critique template

Create the first draft.
Then review it for:
1. factual weakness
2. missing requirement
3. over-claiming
4. unclear wording
5. risky assumption

Rewrite the final answer after the review.
Return both:
- final answer
- short list of fixes made

Anti-hallucination template

Answer only from the provided context.
If the answer is not supported, say: "Not found in provided context."
Cite the exact evidence snippets used.
Do not guess.

Code patch template

You are a senior software engineer.

Task:
Fix the issue in the provided code.

Return:
1. root cause
2. minimal patch
3. tests
4. commands to verify
5. risks

Rules:
- no invented imports or APIs
- preserve existing behavior where possible
- explain any breaking change clearly
