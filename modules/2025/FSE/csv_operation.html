CSV Manipulation via Shell Scripting

Using Linux standard tools like awk, sed, and grep allows for lightning-fast CSV processing without external dependencies.

1. Counting Records

To count records while excluding the header row:

# Method 1: Using wc (includes header)
wc -l data.csv

# Method 2: Excluding the header (best practice)
count=$(tail -n +2 data.csv | wc -l)
echo "Total records: $count"

2. Validating Column Count

Ensure every row has the same number of columns (e.g., 5 columns).

awk -F',' '{ if (NF != 5) print "Error at line " NR ": has " NF " columns" }' data.csv

Note: -F',' sets the field separator to a comma.

3. CSV Syntax Validation

Basic check for empty lines or trailing commas which often break parsers.

# Find empty lines
grep -n "^$" data.csv

# Find lines with trailing commas
grep -n ",$" data.csv

4. File Content Operations

Extracting Specific Columns

Extract only the 1st and 3rd columns:

cut -d',' -f1,3 data.csv > extracted.csv

Searching for Data

Find all records where the 2nd column matches "Completed":

awk -F',' '$2 == "Completed" { print $0 }' data.csv

5. Advanced Use Cases

Task Command
Sort by Column 2 sort -t',' -k2,2 data.csv
Remove Duplicates sort -u data.csv > clean.csv
Sum a Column awk -F',' '{sum+=$3} END {print sum}' data.csv
Pro Tip: If your CSV contains commas inside quoted strings (e.g., "New York, NY"), standard awk might fail. In those cases, use csvkit or python's csv module for parsing.
