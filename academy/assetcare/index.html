From code to production: building AssetCare.

Fourteen modules that follow one real application from its first architecture decision to a public URL on Kubernetes. The application is AssetCare, live today on Java 25, Spring Boot 4.1, Angular 22, PostgreSQL, Keycloak, K3s and Helm; the repository is open, so every module ends with something you can run. This is a case study and engineering walkthrough, published progressively: what is written today is linked, what is still to come is labelled as such.

How to use this series

Read a module, then run the thing it describes.

Who it is for

Engineers who can write a Spring or Angular application and want to see, on a real codebase, everything that surrounds it in production: identity, migrations, containers, a cluster, TLS, a pipeline, backups and operations.

What you need

Java 25, Node 24, Docker. make doctor in the repository checks all three. The setup guide starts from an empty machine and verifies every step. A cloud account is needed only from module 09 onwards.

Where the material lives today

The seven-course walkthrough already covers most modules with why, what, how and proof. The case study covers the live deployment and its verification. Dedicated lessons with exercises are added module by module.

Run it before you read it

git clone https://github.com/Janaka2/spring-angular-production-blueprint.git
cd spring-angular-production-blueprint
cp .env.example .env          # development credentials, labelled as such
docker compose up -d --wait   # PostgreSQL 18, Keycloak 26, MinIO
make backend                  # API on :8080
make frontend                 # SPA on :4200

Then make test, make e2e, and make observability for the dashboards.

Or look at the finished thing first

The live deployment has a public demo account with fictional sample data. Sign in, change something, upload a file, read the audit trail, then come back and find the code that did it.
