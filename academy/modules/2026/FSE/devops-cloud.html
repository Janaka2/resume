DevOps & Cloud: Docker · Kubernetes · CI/CD

This module is now fully available. Use this page as your roadmap: what you will learn, how the study plan is structured, and where to find guided day-by-day deep dives.

Learning outcomes

  • Containerize services with secure, reproducible, multi-stage Docker builds.
  • Deploy and scale workloads on Kubernetes using production-safe manifests.
  • Automate delivery with CI/CD gates, test stages, and progressive rollouts.
  • Operate cloud-native systems with observability, backups, and incident response.

Study plan

Week 1Dockerfiles, image hardening, local compose environments, artifact flow.
Week 2Kubernetes objects, probes, config/secrets, autoscaling strategies.
Week 3CI/CD pipelines, quality gates, release promotion, rollback strategies.
Week 4SRE basics, alerting, runbooks, cost/performance optimization in cloud.
